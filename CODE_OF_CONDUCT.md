# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful. Disagreement is fine and welcome — personal
attacks, harassment, or discriminatory language are not.

Report unacceptable behaviour to the project maintainer via GitHub
(open an issue marked confidential, or email the address listed on the
maintainer's GitHub profile).
